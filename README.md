## Задание 03

Функция `MLE(pdf, x, p0)` возвращает вектор оценок параметров. Она минимизирует отрицательную логарифмическую функцию правдоподобия `-sum(log(pdf(t, p)))` методом Нелдера — Мида.

- `pdf(t, p)` — отдельная функция, возвращающая плотность в точке `t` при векторе параметров `p`.
- `x` — непустая выборка независимых наблюдений из одного распределения (список или массив).
- `p0` — вектор начальных приближений.

### Пример использования

Запустите из корня репозитория:

```bash
python - <<'PY'
from runpy import run_path
import numpy as np
from scipy.stats import norm

MLE = run_path("task-03.py")["MLE"]

def pdf(t, p):
    return norm.pdf(t, loc=p[0], scale=np.exp(p[1]))

x = [1, 2, 2, 3, 4, 5]
p_est = MLE(pdf, x, [0, 0])
print("mu =", p_est[0], "sigma =", np.exp(p_est[1]))
PY
```

Ожидаемый результат: `mu ≈ 2.8333`, `sigma ≈ 1.3437`. В примере параметры — среднее и логарифм стандартного отклонения; `exp(p[1])` обеспечивает положительный масштаб даже при начальном приближении `[0, 0]`.

Выбирайте допустимое начальное приближение, при котором плотности наблюдений положительны. Ограничения параметров учитываются в определении `pdf`, например через перепараметризацию, как выше. Реализация предполагает, что значения плотности в области поиска конечны и положительны; для крайне малых плотностей возможно численное обнуление.

Оптимизация локальная: результат может зависеть от `p0`, а глобальный максимум не гарантируется. Если оптимизатор не сошёлся или итоговое значение не является конечным, функция вызывает `RuntimeError`.
