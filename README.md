# Math Masters 2026

Решения домашних заданий курса.

## Установка

Требуется Python 3. Зависимости для всех заданий перечислены в едином файле [requirements.txt](requirements.txt).

Выполните из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Все команды запуска ниже выполняются в активированном окружении. Для отображения графиков требуется графическая среда.

## Задания

| № | Описание | Решение |
|---|---|---|
| 01 | Построение выборочной функции распределения и оценка выборочной квантили для заданной вероятности | [task-01.py](task-01.py) |
| 02 | Построение ядерной оценки плотности (KDE) для заданной выборки | [task-02.py](task-02.py) |

## Задание 01

### Запуск

```bash
python task-01.py
```

Первая строка ввода — элементы выборки через пробел, вторая — вероятность от 0 до 1.

## Задание 02

Построение KDE с гауссовым ядром и автоматическим выбором ширины окна по правилу Скотта.

### Запуск

```bash
python task-02.py
```

Введите числа через пробел, например `1 2 2 3 4 5`, и нажмите Enter. Нужны хотя бы два конечных числа и ненулевая дисперсия. Десятичный разделитель — точка.
